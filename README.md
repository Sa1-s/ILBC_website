# I Love Being Catholic: parish adult formation website

A multi-page, animated website for the **I Love Being Catholic** adult-formation program from Liguori Publications. The content is adapted from the program brochure shared by Fr. Tom. It is plain HTML, CSS and JavaScript, with no framework and no build step needed to run it.

**Live site:** https://sa1-s.github.io/ILBC_website/

## Pages

| Page | File | What it covers |
|---|---|---|
| Home | `index.html` | Introduction, the five units at a glance, settings, resources, pathway |
| Welcome | `invitation.html` | Why bring the program to a parish and who it is for |
| Formats | `settings.html` | Five Sundays, retreat weekend, five-night mission, OCIA and parish groups, plus a three-question format finder |
| Lessons | `units.html` | The five connected units, a unit explorer with progress, and a glimpse of a gathering |
| Library | `resources.html` | Narrative guide, leader guide, participant guide, podcast companion |
| Pathway | `beginning.html` | The five-week introduction and the five twelve-week studies |
| Get started | `get-started.html` | Planning checklists and a contact form for Liguori Publications |

## Features

- Pastel mint theme built from the supplied palette, with the original seal and Liguori logos kept in their own colours.
- Moves between pages without a browser reload (a small client-side router in `assets/js/main.js`), with back/forward and hash links supported.
- Animations: scroll reveals, count-up numbers, a drawn cross with a rotating ring, parallax banners. All respect `prefers-reduced-motion`.
- A light "Your journey" tracker with seven quests, saved only on the visitor's device (no accounts, no tracking).
- Responsive from 320px phones to desktop, with iPhone safe-area support, touch-friendly tap targets and a Windows high-contrast fallback.
- Self-hosted fonts (Noto Serif and Noto Sans), so no requests go to third-party servers.

## Run it locally

The site needs to be served over HTTP (opening the files directly will not work with the page-to-page navigation).

```bash
# Python
python -m http.server 3000

# or Node
npx serve .
```

Then open http://localhost:3000.

## Project structure

```
index.html, invitation.html, settings.html,
units.html, resources.html, beginning.html, get-started.html
assets/
  css/style.css      all styles and design tokens
  js/main.js         router, animations, journey tracker, quiz, forms
  img/               seal, Liguori logo, photographs
  fonts/             self-hosted woff2 fonts
tools/build_site.py  generates the seven HTML pages
```

## Editing the content

The seven HTML files are generated by `tools/build_site.py`, which holds all the page copy. To change wording:

1. Edit the text in `tools/build_site.py`.
2. Run `python tools/build_site.py` to regenerate the pages.
3. Commit and push.

Styles live in `assets/css/style.css`. The colour tokens are at the top of that file.

## Deploying

The site is hosted with GitHub Pages straight from the `main` branch (Settings, Pages, Deploy from a branch, `main`, `/ (root)`). To use a custom domain, add it under Settings, Pages, then create the matching DNS records with your domain provider.
